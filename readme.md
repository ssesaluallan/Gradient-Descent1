# Neural Network with Gradient Descent

This script trains a small neural network to classify three groups of 2D points. It generates sample data, trains the network using mini-batch gradient descent, and displays the training loss and classification decision regions.

## Requirements

- Python 3
- NumPy
- Matplotlib
- scikit-learn

Install the required packages with:

```bash
python -m pip install numpy matplotlib scikit-learn
```

## Run

From this folder, run:

```bash
python neuralNetwork.py
```

Two plots will open: the loss during training and the network's predicted decision regions.
